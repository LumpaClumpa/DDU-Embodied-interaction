DDU Embodied Interaction - how to run
=====================================

Setup
-----

Needs Windows 10/11, Git, a webcam, and Python 3.12 + 3.10 from python.org.
In PowerShell:

    git clone https://github.com/LumpaClumpa/DDU-Embodied-interaction.git
    cd DDU-Embodied-interaction
    .\setup.ps1                 # add -SkipTraining to skip the 3.10 env

This creates two environments:

    .venv              Python 3.12, camera apps     (requirements-app.txt)
    .venv-mediapipe    Python 3.10, model training  (requirements.txt)

Activate the one you need:

    .\.venv\Scripts\Activate.ps1
    .\.venv-mediapipe\Scripts\Activate.ps1

If PowerShell blocks scripts, allow them for this window only:

    Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass

Apps (in .venv)
---------------

Press q in the camera window to quit. All apps use
models\my_custom_gesture\gesture_recognizer.task; pass --model to use another.

python main.py
    Shows hand landmarks and the recognized gesture.

python trash_talk.py
    Hold a gesture briefly to get a trash-talk message on screen. Players are
    "Left" and "Right" by screen side. Edit MESSAGES in trash_talk.py.

python music_control.py   (start music in any player first)
    Hold a closed fist        play / pause
    Swipe open hand           next / previous track (fast, sideways, smooth;
                              the meter at the top turns green when it counts)
    Pinch + move up / down    volume
    Frame with both hands     open / resize / close the visualizer: make an
                              "L" with thumb and index of each hand, drag
                              apart, relax to place; a small frame closes it
    The visualizer shows song title, artist, cover art and audio bars.
    Controls only react with one hand in view. Add --dry-run to test without
    sending media keys. Tune the SWIPE_* constants at the top of the file.

    Optional trained gestures (dataset folder names must match):
        palm_stop      pause
        point_right    next track      (as seen in the mirrored window)
        point_left     previous track
        thumb_down     mute / unmute
        rock_horns     rock mode colours
        shaka          skip 2-5 tracks

Training (in .venv-mediapipe)
-----------------------------

Put images in one folder per label under data\gesture_dataset\. A "none"
folder is required. Then:

    python training_models.py --export-dir models\my_custom_gesture

- Defaults: 100 epochs, batch 32, learning rate 0.002, dropout 0.4
  (change with --epochs, --batch-size, --learning-rate, --dropout).
- Sideways phone photos are rotated upright automatically; originals are
  not changed.
- Adding a class: add its folder and rerun with the same --export-dir. The
  old model is only replaced if training succeeds. Removing or renaming a
  class needs a new --export-dir.
- --sample-data trains on the Rock-Paper-Scissors example dataset.

Manual training setup (setup.ps1 does this; order matters):

    py -3.10 -m venv .venv-mediapipe
    .\.venv-mediapipe\Scripts\Activate.ps1
    python -m pip install "Cython<3" "setuptools<81" wheel
    python -m pip install --no-build-isolation "PyYAML==5.4.1"
    python -m pip install -r requirements.txt
    python -m pip install --no-deps "protobuf==3.20.3"

Troubleshooting
---------------

- Camera does not open: check it is connected and not used by another app
  (camera index 0 is used).
- Install fails: check the Python version (3.12 for .venv, 3.10 for
  .venv-mediapipe) and rerun .\setup.ps1.
- Install fails with "No such file or directory" and a long-path hint: the
  folder path is too long for Windows. Clone into a short folder (e.g.
  C:\code) and run .\setup.ps1 again.
